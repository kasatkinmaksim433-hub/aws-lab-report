# Результати тестування

* **Frontend**: Прямий доступ до S3-бакета працює; CloudFront пропущено через обмеження `voclabs`[cite: 1].
* **ALB**: Запити успішно обробляються двома `healthy` інстансами[cite: 1].
* **Lambda**: Пропущено через обмеження `iam:CreateRole`.
* **Відмова EC2**: При зупинці одного вузла балансувальник переспрямовує трафік на працюючий.
